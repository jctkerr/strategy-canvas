# Bookshop tree preview

`bookshop-tree.png` is a screenshot of the actual bundled canvas, captured on
11 September 2026 in Chromium through the browser tool. It shows all eight nodes
from `examples/bookshop-walkthrough.json`; the snapshot is fictional.

Source page: `docs/bookshop.html`, generated by `python3 scripts/build_demo.py`.
The screenshot is limited to the tree region so labels remain readable in the
README. No nodes, figures or interface elements were generated or repainted.

The visible issue tree contains a driver subtree. The before/after arithmetic,
preserved branches and local editing checks are recorded in
`docs/test-evidence/readme-example/checks.json`.
