# Strategy Canvas picture guide

[Full-size PNG](strategy-canvas-setup-guide.png). Created 10 September 2026 using OpenAI's built-in image generator, then edited to cover multiple agents. This is an instructional illustration, not a screenshot of the canvas.

The [README](../../README.md#with-your-ai-tool) has the copyable instruction and app-specific steps. The [compatibility record](../compatibility.md) distinguishes tested routes from documented routes. The fictional bookshop illustrates an [issue tree](../../references/tree-methods.md); its questions are not findings.

## Design prompt

Create a portrait 4:5 instructional one-pager. Use a floating warm ivory panel with gently rounded corners and a soft shadow over a photograph of pale limestone steps, diagonal sunlight and a glimpse of blue sea. Keep deep navy sans serif typography, fine sage rules, generous margins and the personal footer James Kerr · jameskerr.me. Keep the URL and all text exact. Arrange three numbered steps vertically, the pasteable instruction in a light sage inset, then one parent question branching down to three equal child questions. Preserve readability at phone size. Do not add app logos, pretend interface controls or numerical answers.

## Exact copy

```text
STRATEGY CANVAS
Think it through.
One branch at a time.

1  Open your AI tool
Codex, Claude Code, Cursor or similar.

2  Paste this and add your question
Install and use Strategy Canvas:
https://github.com/jctkerr/strategy-canvas

Read the skill and open the canvas beside our chat.
My question: [type your question]

3  Press Send
Talk it through. Click a card to edit. Use + to add a branch.

EXAMPLE · ISSUE TREE
Break one question into smaller questions.
Could a bookshop run paid workshops?
Will people pay?
Will it cover costs?
Can we staff it?

James Kerr · jameskerr.me
```
